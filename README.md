# CyberShield

CyberShield is a full-stack web application designed to help users learn fundamental cybersecurity concepts through clear and interactive content.  
The project focuses on building a clean frontend, a structured backend, and secure communication between them.

This project was built to practice real-world full-stack development while applying basic security-aware design principles.

---

## Tech Stack

### Frontend
- React
- JavaScript
- HTML / CSS

### Backend
- Node.js
- Express.js
- REST APIs

### Tools
- Git
- GitHub

---

## Features

- Educational cybersecurity content delivered through a web interface  
- React-based frontend connected to a Node.js backend  
- RESTful API communication between frontend and backend  
- Component-based UI structure and organized routing  
- Basic security considerations in backend logic and API handling  

---

## Project Goals

- Practice building a complete full-stack web application  
- Strengthen frontend–backend integration skills  
- Apply structured and secure API design  
- Improve code organization, readability, and maintainability  

---
